  GITHUB DEPLOYMENT - QUICK REFERENCE
═══════════════════════════════════════════════════════════════

⚠️  BEFORE YOU PUSH - IMPORTANT!
═══════════════════════════════════════════════════════════════

1. Update vite.config.js (line 7):
   
   Change this:
   base: process.env.GITHUB_PAGES ? '/project-1/' : '/',
   
   To this (replace with YOUR repository name):
   base: process.env.GITHUB_PAGES ? '/YOUR-REPO-NAME/' : '/',


📤 PUSH TO GITHUB
═══════════════════════════════════════════════════════════════

Run these commands in order:

1. git add .
2. git commit -m "Initial commit: Sararah Architects landing page"
3. git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
4. git branch -M main
5. git push -u origin main


⚙️  ENABLE GITHUB PAGES
═══════════════════════════════════════════════════════════════

1. Go to: https://github.com/YOUR-USERNAME/YOUR-REPO-NAME
2. Click: Settings (top right)
3. Click: Pages (left sidebar)
4. Under "Source": Select "GitHub Actions"
5. Click: Save


⏳ WAIT FOR DEPLOYMENT
═══════════════════════════════════════════════════════════════

1. Go to: Actions tab
2. Watch the "Deploy to GitHub Pages" workflow
3. Wait 2-3 minutes for completion
4. Look for green checkmark ✅


🌐 YOUR WEBSITE WILL BE LIVE AT:
═══════════════════════════════════════════════════════════════

https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

Example:
- Username: rahul123
- Repo: sararah-architects
- URL: https://rahul123.github.io/sararah-architects/


🔄 FUTURE UPDATES
═══════════════════════════════════════════════════════════════

To update your website:

1. Make changes to your code
2. git add .
3. git commit -m "Update: description"
4. git push

GitHub Actions will automatically rebuild and deploy!

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ 404 Error on website?
   → Check vite.config.js base path matches repo name

❌ CSS/Images not loading?
   → Check vite.config.js base path

❌ Can't push to GitHub?
   → Use Personal Access Token as password
   → Or set up SSH keys

❌ Workflow fails?
   → Check Actions tab for error details
   → Verify package.json has all dependencies
